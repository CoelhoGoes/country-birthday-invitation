# Arquivos de áudio necessários

Adicione aqui os arquivos `.mp3` referenciados pelo código (o site funciona
sem eles, mas os efeitos sonoros ficam silenciosos até que existam):

- `spur-hover.mp3` — tilintar de esporas, tocado no hover dos `SoundButton`.
- `lasso-success.mp3` — som de laço (rope swoosh), tocado ao clicar em
  `SoundButton` (ex: confirmar presença).

Sugestões de fontes gratuitas (ver `docs/design-reference.md`):
- Freesound.org (buscar "spurs", "lasso", "cowboy", "boots")
- Pixabay Sound Effects (pixabay.com/sound-effects)
- Zapsplat.com (categoria Western/Country)
- Mixkit.co/free-sound-effects
